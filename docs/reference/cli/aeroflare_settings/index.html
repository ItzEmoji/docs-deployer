aeroflare_settings

aeroflare settings​

Configure local preferences (theme, logins, cache URL)

Synopsis​

Configure local, per-machine preferences -- appearance theme, registry logins, and the default cache URL -- and save them to aeroflare.yaml.

These settings are local to this machine. To configure the remote cache itself (such as its signing public key), use "aeroflare configure".

aeroflare settings [flags]
